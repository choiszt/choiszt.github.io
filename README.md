# Shuai Liu

Personal homepage for Shuai Liu.

I am a PhD student at [MMLab@NTU](https://www.mmlab-ntu.com/), supervised by [Prof. Ziwei Liu](https://liuziwei7.github.io/).

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Structure

- `index.html`: page content and metadata
- `src/main.ts`: client-side interactions
- `src/style.css`: site styling
- `assets/` and `public/`: static assets
